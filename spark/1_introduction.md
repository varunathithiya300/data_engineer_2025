1. Apache Spark is an `unified computing engine` and `a set of libraries` for `parallel processing` on a `computing cluster`.

2. Unified - It is a common platform where all types of data professionals can collaborate i.e., data analyst, data engineer, data scientist

3. Computing engine - A computing engine is a computer that helps to process information. The architecture is very similar to the desktop/laptop we use i.e., CPU (core) and RAM. Spark does all the work in memory -> It does not store data anywhere.

4. Computing cluster - Is a collection of computers (also called nodes).

5. Architecture - Master -> Slave -> (driver node -> worker nodes)
